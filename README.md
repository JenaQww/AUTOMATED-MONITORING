# Автоматизированный мониторинг и реагирование на угрозы (Python)

Инструмент для сбора событий информационной безопасности из сетевых логов и внешних API, аналитической обработки индикаторов компрометации, имитации оперативного реагирования и генерации отчётности с визуализацией.

## Функциональные возможности

1. **Сбор данных (3 источника)**:
   - **Логи Suricata (`data/suricata_eve.json`)** — парсинг событий сетевой безопасности в формате EVE JSON (DNS-запросы и срабатывания сигнатур IDS).
   - **API Vulners (`https://vulners.com/api/v3/search/lucene/`)** — получение сведений об актуальных уязвимостях программного обеспечения и их оценках по шкале CVSS v3.1 (с автоматическим переключением на локальный дамп `data/vulners_sample.json` при отсутствии переменной окружения `VULNERS_API_KEY`).
   - **API VirusTotal v3 (`https://www.virustotal.com/api/v3/ip_addresses/{ip}`)** — проверка репутации внешних IP-адресов по базе антивирусных движков (с автоматическим переключением на локальный дамп `data/virustotal_sample.json` при отсутствии переменной окружения `VT_API_KEY`).
2. **Анализ данных (`pandas`, `json`, `requests`)**:
   - Подсчёт интенсивности DNS-запросов и сигнатурных оповещений Suricata в разрезе каждого IP-адреса.
   - Выявление подозрительного сетевого трафика (превышение порога `DNS_QUERY_THRESHOLD = 15`, наличие критических сигнатур Suricata или `>= 3` срабатываний антивирусных движков VirusTotal).
   - Расчёт интегрального индекса риска узла (`risk_score`) и фильтрация опасных уязвимостей с баллом `CVSS >= 7.0`.
3. **Реагирование на угрозы**:
   - Вывод детализированных предупреждений в консоль.
   - Имитация блокировки вредоносных IP-адресов на межсетевом экране (`iptables -A INPUT -s <IP> -j DROP`).
   - Имитация отправки уведомлений дежурной смене SOC в Telegram и по электронной почте (при задании переменных `TG_BOT_TOKEN` и `TG_CHAT_ID` выполняется реальный вызов Telegram Bot API).
4. **Отчётность и визуализация**:
   - Сохранение сводного отчёта об обнаруженных угрозах и мерах реагирования в файлы `threat_report.json` и `threat_report.csv`.
   - Построение двухпанельного аналитического графика `threat_analysis_chart.png` (топ-5 подозрительных IP-адресов и распределение баллов CVSS v3.1).

## Структура репозитория

- `threat_monitor.py` — основной исполняемый скрипт мониторинга и реагирования.
- `data/suricata_eve.json` — журнал событий сетевой безопасности Suricata в формате EVE JSON.
- `data/vulners_sample.json` — кэшированный ответ API Vulners для автономной проверки.
- `data/virustotal_sample.json` — кэшированный ответ API VirusTotal v3 для автономной проверки.
- `threat_report.json` — сгенерированный детализированный отчёт в формате JSON.
- `threat_report.csv` — сгенерированная сводная таблица обнаруженных угроз в формате CSV.
- `threat_analysis_chart.png` — график распределения угроз (топ-5 IP и оценки CVSS).
- `requirements.txt` — список зависимостей проекта.

## Установка и запуск

1. Установите необходимые библиотеки:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите скрипт:
   ```bash
   python3 threat_monitor.py
   ```
3. *(Необязательно)* Для выполнения живых запросов к онлайн-сервисам перед запуском задайте ключи API в переменных окружения:
   ```bash
   export VT_API_KEY="ваш_ключ_virustotal"
   export VULNERS_API_KEY="ваш_ключ_vulners"
   python3 threat_monitor.py
   ```
   При отсутствии ключей скрипт автоматически использует подготовленные наборы данных из каталога `data/`, что позволяет проверить всю логику работы без регистрации во внешних сервисах.
